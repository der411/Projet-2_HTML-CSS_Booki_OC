Ce projet consiste à développer la page d'un site Internet pour permettre aux usagers de trouver des hébergements et des activités dans la ville de leur choix.

# Aperçu
![Aperçu de la page](https://live.staticflickr.com/65535/53899929404_49a6aff123_n.jpg)

# Installation
- Télécharger le fichier ZIP du projet depuis le dépôt GitHub.
- Extraire les fichiers de l'archive ZIP sur votre ordinateur.
- Ouvrir le dossier du projet dans Visual Studio Code.
- En utilisant l'extension Live Server: clic droit sur le fichier HTML, et sélectionner "Open with Live Server".

# Fonctionnalités
- Recherche d'hébergements et d'activités par ville
- Interface responsive pour desktop, tablette et mobile
- Intégration des maquettes fournies par l'UI designer

# Technologies Utilisées
- HTML
- CSS
- Flexbox pour le responsive design
